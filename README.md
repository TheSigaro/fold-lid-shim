# FoldLidShim

Костыль для Galaxy Z Fold7 (SM-F966B, Android 16) с мёртвым датчиком Холла: система не засчитывает закрытие, SW_LID не срабатывает. Приложение следит за углом шарнира (`Sensor.TYPE_HINGE_ANGLE`) и при закрытии переводит телефон в состояние CLOSED командой `cmd device_state state 0`, а при раскрытии снимает override командой `cmd device_state state reset`. Команды выполняются через Shizuku (процесс под uid shell), root не нужен.

Логика: угол <= 8 градусов дольше 400 мс - `state 0` (один раз), угол >= 25 градусов - `state reset` (один раз), между порогами ничего не происходит. Пороги меняются на главном экране.

## Сборка

Нужен только Docker, Android SDK на хосте не нужен:

```
./build.sh
```

Готовый debug APK (подпись debug) окажется в `out/app-debug.apk`. Установка: `adb install -r out/app-debug.apk`.

## Установка и настройка

1. Установите Shizuku из Play Store (пакет `moe.shizuku.privileged.api`).
2. Запустите Shizuku одним из способов:
   - через adb: `adb shell sh /sdcard/Android/data/moe.shizuku.privileged.api/start.sh`;
   - через беспроводную отладку: Параметры - Для разработчиков - Беспроводная отладка, затем в приложении Shizuku "Запуск через беспроводную отладку" и сопряжение по коду.
3. Откройте FoldLidShim, нажмите "Запросить разрешение Shizuku" и подтвердите. Статус Shizuku на экране должен стать "готов".
4. Разрешите уведомления (запрос появляется при старте).
5. Нажмите "Оптимизация батареи" и разрешите приложению работать без ограничений.
6. Нажмите "Проверить сейчас": экран должен переключиться на внешний на 3 секунды и вернуться.
7. Включите переключатель "Служба включена". В шторке появится постоянное уведомление с текущим углом и состоянием override.

## После перезагрузки

Если служба была включена, она стартует сама (BOOT_COMPLETED). Shizuku после перезагрузки сам не запускается (при запуске через adb), поэтому служба показывает в уведомлении "Ожидание Shizuku" и работает без падений. Запустите Shizuku заново (adb или беспроводная отладка), приложение подхватит его автоматически и продолжит работу с последнего известного угла. Если Shizuku запущен, но разрешение отозвано, откройте приложение и запросите его снова.

## Как отключить

- Выключите переключатель "Служба включена": при остановке служба снимает свой override.
- Если override завис (например, процесс убит), снимите его вручную: `adb shell cmd device_state state reset`.

## Логи

`adb logcat -s FoldLidShim` - каждое изменение состояния и каждая команда с кодом возврата и выводом.
