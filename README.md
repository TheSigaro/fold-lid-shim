# FoldLidShim

Переключает экраны Galaxy Z Fold7 при неисправном датчике крышки по углу шарнира и магнитометру, без root.

## Зачем

При неисправном датчике Холла телефон может оставаться в состоянии «открыто» после складывания или «закрыто» после раскрытия. FoldLidShim помогает при залипании «открыто»: запрашивает внешний экран по датчикам, а при раскрытии снимает свой запрос и возвращает управление прошивке.

Снаружи поломка выглядит так: сложенный телефон продолжает показывать внутренний экран и не переходит на внешний, а раскрытый остаётся на внешнем. Диагностика датчиков Samsung при этом может сообщать «работает нормально»: она опрашивает датчики сенсорного хаба, а прошивка определяет положение крышки по переключателю ядра `flip` (SW_LID), который и залипает.

Приложение написано на Kotlin для Galaxy Z Fold7 (SM-F966B), Android 16. Источник угла по умолчанию - `hinge_angle`. Доступ к Samsung Folding Angle и Accelerometer-Sub закрыт разрешением `com.samsung.permission.SSENSOR` уровня signature|privileged, которое приложение и shell получить не могут.

Диагноз в приложении строится по настоящему hinge и состоянию системы без собственного запроса. Это наблюдение за текущей сессией службы; подробности в [описании диагноза Холла](docs/behavior.md#диагноз-холла-и-что-делает-костыль).

## Что умеет

- Запрашивает CLOSED при складывании: при включённом экране без выдержки, по умолчанию при угле <=10°. Ранний запрос включён при <=45° и скорости складывания >=90°/с. В замере на устройстве с работающим Холлом внешний экран включался через 85-120 мс после решения.
- Снимает собственный запрос при раскрытии. Порог по умолчанию 15°; в первые 1,5 с после CLOSED раскрытие только по hinge проходит защиту от дребезга 300 мс.
- Предусматривает работу на заблокированном и спящем телефоне: CLOSED сохраняется при засыпании. При складывании во сне без своего запроса выдержка составляет 1000 мс; раскрытие по магнитометру требует подтверждения, по замеру около 250-500 мс после первого события. Пределы проверки указаны ниже.
- Следует исправному Холлу: если система уже CLOSED, собственного запроса нет; системное раскрытие сбрасывает старое решение о закрытии.
- Не запрашивает CLOSED при остановке в Flex-положении 70-120°.
- Обнаруживает признаки залипания «закрыто», но исправить его на проверенной прошивке может только adb.
- Даёт плитку быстрых настроек «Экран Fold» и кнопки «Закрыть принудительно» и «Открыть принудительно».

## Как это работает

Служба читает выбранный источник угла через `AngleSource`. Магнитометр с компенсацией вращения гироскопом позволяет предварительно распознать движение крышки; hinge подтверждает решение. Политика учитывает состояние системы, собственный запрос и сон телефона.

```text
hinge_angle + магнитометр/гироскоп -> решение о закрытии
  -> StateActivity -> DeviceStateManager: CLOSED (0), REQUEST_FLAGS = 2
  -> диалог Samsung -> служба спецвозможностей подтверждает -> внешний экран
раскрытие -> StateActivity -> cancel собственного запроса
```

Флаг 2 сохраняет запрос при засыпании. Автоподтверждение ограничено системным диалогом `com.android.systemui` при ожидающем запросе приложения и включённой службе.

Подробности: [Поведение службы](docs/behavior.md), [Магнитометр](docs/magnetometer.md).

## Ограничения

- Прошивка SM-F966B с Android 16 отклоняет запрос OPENED приложению с `SecurityException`: при залипании «закрыто» нужен adb с компьютера. При таком залипании `hinge_angle` всегда 0, поэтому путь OPENED по hinge даже не запускается.
- Нужны разрешение показа поверх других приложений и включённая служба специальных возможностей для автоматического подтверждения диалога Samsung.
- Часть сценариев с неисправным Холлом, включая складывание и раскрытие спящего телефона, [не проверена](TESTING.md#что-не-проверено).
- Расход батареи за сутки не замерялся. Магнитометр и гироскоп non-wakeup не будят процессор; с включённой экономией при погашенном экране работает обычный hinge.
- Проверено только на Galaxy Z Fold7 SM-F966B с Android 16. Используется скрытый API `DeviceStateManager`; поведение зависит от прошивки.
- Чужое магнитное поле, повторяющее движение магнита крышки внутри допустимой оболочки, в общем случае неотличимо от настоящего. Гарантии для любого внешнего магнита нет.

## Установка

Нужен Galaxy Z Fold7 с Android 16 без root. Для сборки через Docker:

```sh
./build.sh
```

Результат - `out/app-debug.apk`. Скрипт выполняет модульные тесты, lint и сборку APK. Альтернатива с JDK 17 и Android SDK 36 (platform android-36, build-tools 36.0.0):

```sh
./gradlew --no-daemon testDebugUnitTest lintDebug assembleDebug
```

APK Gradle: `app/build/outputs/apk/debug/app-debug.apk`.

Устанавливайте только на раскрытый телефон без активного запроса CLOSED: установка убивает процесс, а его запрос может остаться и заблокировать внутренний экран. [Причина и восстановление](docs/behavior.md#остановка-и-логи).

```sh
adb shell dumpsys device_state | grep 'Override Request active'
```

Убедитесь, что результат `false`, затем установите APK (для Gradle используйте путь выше):

```sh
adb install -r out/app-debug.apk
```

1. Разрешите показ поверх других приложений.
2. Нажмите «Включить в настройках» и включите «FoldLidShim - подтверждение экрана» в специальных возможностях Android.
3. Вернитесь в приложение, проверьте статус «Автоподтверждение: включено» и включите службу FoldLidShim.

После обновления служба запускается через `MY_PACKAGE_REPLACED`, если переключатель был включён; службу спецвозможностей система перепривязывает сама.

## Настройка и использование

Главный экран поддерживает светлую и тёмную темы. Карточка статуса показывает состояние телефона, угол, диагноз Холла, действие приложения и переключатель службы.

| Поле или карточка | Назначение |
| --- | --- |
| Источник угла | `hinge` по умолчанию; `samsung` и `accel` требуют закрытых SSENSOR-датчиков. Недоступный источник автоматически не заменяется. |
| Пороги | Закрытие 10°, раскрытие 15° по умолчанию; допустимо `0 <= закрыто < открыто <= 180`. Кнопка «Сохранить пороги» применяет значения. |
| Ранний запрос при складывании | Включён по умолчанию; угол 45°, настраивается в пределах 15-90° и не ниже порога закрытия. Скорость >=90°/с считается между событиями с интервалом не более 500 мс. |
| Автоподтверждение | Статус службы спецвозможностей и переход к её включению. |
| Поверх других приложений | Статус разрешения и переход к его выдаче. |
| Магнитометр | Включён по умолчанию; показывает последнее событие, опережение, ложные события и калибровку. [Алгоритм и калибровка H](docs/magnetometer.md#калибровка-h). |
| Экономия датчиков | Включена по умолчанию; отключает магнитометр и гироскоп при погашенном экране. |
| Запись датчиков | Отдельная запись CSV с метками, до 90 с или 30 МБ. [Инструкция и формат](docs/sensor-recording.md). |
| Датчики | Свёрнутая карточка с сырыми значениями и инверсией осей sub для `accel`. Обновляется каждые 200 мс только в раскрытом виде при активном UI. |
| Шторка уведомлений | Пояснение об обязательном уведомлении службы. |

В карточке «Ручное управление»:

- «Закрыть принудительно» запрашивает CLOSED через StateActivity. При выключенной службе диалог Samsung нужно подтвердить вручную.
- «Открыть принудительно» снимает собственный запрос; это не запрос OPENED. Ручное снятие подавляет автоматическое повторное закрытие до смены направления.
- «Проверить сейчас» запрашивает закрытие и через 3 с снимает запрос, даже если UI ушёл в фон.

Добавьте «Экран Fold» через редактирование быстрых настроек. Плитка показывает текущее состояние и запускает только снятие запроса; работает и без запущенной службы. При недоступном DeviceStateManager плитка недоступна.

Уведомление службы уже создаётся тихим на канале минимальной важности, разрешение `POST_NOTIFICATIONS` приложение не запрашивает. Полностью убрать обязательную иконку через публичный API нельзя; видимость зависит от канала и системного разрешения. Android может показывать службу в списке активных приложений. [Подробности](docs/behavior.md#как-убрать-уведомления-из-шторки).

Выключение службы сначала снимает запрос и ждёт подтверждения. При отказе служба остаётся для повторов и показывает ошибку. Полное описание [главного экрана](docs/behavior.md#главный-экран) и [плитки](docs/behavior.md#плитка).

## Диагностика

Кнопка «Журнал» показывает последние записи приватного `files/timeline.log`. Файл UTF-8, порядок хронологический; лимит 65536 байт, при заполнении сохраняются последние примерно 32 КБ. Формат строки:

```text
<unix-ms> elapsedNs=<монотонное-время> <событие и поля>
```

Чтение последних записей для debug APK (`run-as` требует debuggable APK):

```sh
adb shell run-as dev.pavlov.foldlidshim tail -40 files/timeline.log
```

Пробуждения и засыпания:

```sh
adb shell logcat -d -v monotonic | grep -E "PowerManagerService: (Waking up|Going to sleep)"
```

[Журнал событий](docs/behavior.md#журнал-событий) описывает поля и ограничения записи. [TESTING.md](TESTING.md#ручные-проверки-на-устройстве) содержит ожидаемые последовательности событий, измеренные задержки и ручные проверки.
